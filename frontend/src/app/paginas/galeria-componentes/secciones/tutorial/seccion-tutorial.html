Overlay del tutorial guiado de la partida. Resalta el elemento marcado con data-tutorial, muestra el paso actual y no bloquea el tablero. En esta vista previa se muestra el globo con el paso de cupones.

El overlay real se monta en /usuario/tutorial junto al tablero en modo mock. El velo y el spotlight no capturan punteros para que el jugador pueda arrastrar cartas mientras lee el paso.
